# 宠物小精灵闯关

Java 控制台文字冒险游戏：在 9x9 随机地图上探索、开宝箱、打怪、收集宠物与装备，穿过传送门一关一关往下走。

## 运行

推荐 IDEA 直接运行 `org.zlf.pokemon.Launcher`。

命令行（Git Bash）：

```bash
mkdir -p out
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out -Dfile.encoding=UTF-8 org.zlf.pokemon.Launcher
```

## 操作

| 按键 | 作用 |
|------|------|
| `W` `A` `S` `D` | 上 / 左 / 下 / 右 移动（需大写，或开 CapsLock） |
| `E` | 退出（会再确认一次） |
| `G` | GM 调试菜单（见下） |
| `Y` / `N` | 所有询问的 是 / 否 |
| `B` | 任意询问处查看背包（只读列举，看完继续询问） |

### GM 调试菜单

方向选择处按 `G` 进入，用于手动测试：

1. 揭开当前关卡全图
2. 传送到下一关
3. 发放皮卡丘
4. 发放神装（8 件满属性，直接穿戴）
5. 全队回满血
0. 返回游戏

## 玩法要点

- 第一关出生点旁固定是初级怪物象牙猪；后续关卡出生点旁是回退传送门。
- 宝箱开出 药品 : 装备 : 宠物 ≈ 6 : 3 : 1，怪物掉落同比例。
- 战斗中宠物生命低于 50% 会询问是否服药；药品耗尽后可用低关卡药品。
- 宠物可穿戴 8 件装备（头盔/铠甲/护腿/鞋子/武器/项链/戒指/手镯），同类装备自动比较优劣。
- 打到同类宠物可选择融合升星（最高 10 星）。
- 全队阵亡不结束游戏：全员复活并传送回第一关。

## 项目结构

```
src/org/zlf/pokemon/
├── Launcher.java          # 入口
├── Adventurer.java        # 冒险家：主循环、战斗、背包、GM菜单
├── level/                 # 关卡与 9x9 地图
├── item/
│   ├── HP.java            # 药品（天山雪莲）
│   ├── Treasure.java      # 宝箱
│   ├── Portal.java        # 传送门
│   ├── equipment/         # 8 类装备（含 GM 神装工厂 GodEquipment）
│   ├── monster/           # 4 档怪物：象牙猪(初)/牛魔怪(中)/铁炮鱼(高)/火焰鸟(究)
│   └── pokemon/           # 4 种宠物：妙蛙种子/雷精灵/小火龙/比卡丘
└── util/Tools.java        # 随机数与控制台输入
```
